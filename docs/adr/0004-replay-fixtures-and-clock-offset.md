# 4. Replay adapter with a clock offset, and synthetic fixtures

Date: 2026-10-28 · Status: accepted

## Context

The development environment cannot reach transit APIs, and a portfolio project should still show a
live-looking map to anyone who runs `docker compose up` — without asking them to register for API
keys first. Recorded feeds are also the only way to test "messy upstream data" deterministically.

## Decision

A `ReplayFeedAdapter` implements the same `FeedAdapter` interface as the live HTTP adapters and
plays a directory of recorded protobuf snapshots on a loop at real-time speed. **Replay is the
default profile**; live mode is one environment variable away.

Recorded timestamps are **not rewritten**. Instead each `FeedSnapshot` carries a `clockOffset`
(feed clock minus wall clock); the position engine computes in feed time and converts its outputs
back to wall-clock time. The bytes stay exactly as recorded, so the decoder — extensions included —
is exercised on authentic payloads, and swapping in a real recording is a file copy.

Because real MTA recordings could not be downloaded here, the fixtures in `fixtures/` are
**synthetic**: generated by `scripts/fixtures/gen_*.py` in the real wire formats (GTFS CSV,
GTFS-realtime protobuf with the NYCT extensions), with hand-entered, approximate station
coordinates. `fixtures/README.md` labels every file and `scripts/fetch_real_data.sh` downloads and
records the real thing.

The recordings deliberately contain messy data — a frozen feed, a vanishing trip, predictions that
jump backwards, a duplicated trip — so the stale rules and de-duplication have something to chew on.

## Consequences

- `docker compose up` shows a moving map with no credentials, offline.
- Tests are deterministic: a fixed clock plus a fixed recording gives fixed coordinates.
- The fixtures are **not real-world data** and must never be presented as accurate. Every
  generated file says so in its header or its manifest.
- A little complexity rides along in the clock offset. The alternative — rewriting timestamps on
  the fly — would have corrupted the recordings and hidden decoder bugs.
